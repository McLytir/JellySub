Web / Desktop Client Integration

To add JellySub actions to the main Jellyfin browser/Desktop interface, install the JellySub web-client patch into the Jellyfin web root. You can try the automatic installer below for default server paths, or download a platform script and run it manually.

If the automatic installer cannot patch your setup, download the script for your platform, run it on the machine that hosts the Jellyfin web files, then restart Jellyfin or Jellyfin Desktop and clear the client cache.
