What JellySub does

JellySub finds subtitles for one item, a folder/season/series, or your entire library. You can search on demand, let the plugin pick the best match automatically, or run a full scan that fills in missing subtitles in the background.

The same actions are available in two ways: inside Jellyfin's plugin pages (this settings page plus the unified JellySub Operations page), or through the optional JellySub web-client patch, which adds subtitle actions directly to the item and library UI in Jellyfin's web interface or desktop app.

  • Single item: search from metadata or manual text and choose the subtitle you want.
  • Folder / series: analyse every episode, then download subtitles in auto or guided mode.
  • Whole library: run a scheduled or on-demand scan for every video missing your preferred language(s).

Configure your preferred sources and languages first, then decide whether you want the default item click behaviour to be Assisted (review results before downloading) or Auto (silent best-match download).

Web / Desktop Client Integration

To add JellySub actions to the main Jellyfin browser/Desktop interface, install the JellySub web-client patch into the Jellyfin web root. You can try the automatic installer below for default server paths, or download a platform script and run it manually.

If the automatic installer cannot patch your setup, download the script for your platform, run it on the machine that hosts the Jellyfin web files, then restart Jellyfin or Jellyfin Desktop and clear the client cache.
